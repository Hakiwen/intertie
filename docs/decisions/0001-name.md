# 0001: Name: Intertie

Date: 2026-10-29 · Status: accepted (renaming later is cheap; GitHub redirects)

## Context
Criteria: no trademark issue (never "slack" in the name), no collision with a known
protocol or chat product, `Hakiwen/<name>` free, plausible .dev/.org domain, ideally
free on npm (the reference implementation is TypeScript).

Already rejected in the brief: openchannels, partyline, backchannel, peerline, openconnect.

## Decision
**Intertie.** In power systems, an intertie is a direct interconnection between two
independent grids, owned by the two utilities, with nothing in between. It is the
no-intermediary property in one word. Package scope `@intertie/*`; well-known path
`/.well-known/intertie`; target domain `intertie.dev` (Ben's purchase).

## Consequences
- Generic energy-sector term, so a narrow software trademark is still plausible but not
  guaranteed; a real trademark search is Ben's call before any public launch.
